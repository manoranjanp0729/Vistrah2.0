# Vistra Referral Program

## Rule
When an existing user refers a genuinely new user and the referred user completes their first Vistra work, both users receive 20% off their next eligible Vistra service.

## Recommended controls
- One qualifying reward per referred user.
- Reward is triggered by a server-side completed-work event, not by registration alone.
- Refund/cancellation does not qualify.
- Set a maximum discount amount and expiry period in business configuration.
- Do not allow stacking with incompatible promotions.
- Detect self-referral/fraud before issuing rewards.
