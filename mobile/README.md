# VISTRAH mobile

Native Android/iOS application with the reference dark theme and the existing
VISTRAH API. See [setup, implemented flows and validation limits](../docs/MOBILE.md).

Start: `npm ci`, copy `.env.example` to `.env`, configure reachable development
services, then `npm start`.

Checks: `npm run typecheck`, `npm run lint`, `npm run test`.

Provider evidence, seller management, admin and checkout open the existing
website. Store builds and on-device validation are pending.
